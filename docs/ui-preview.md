# 界面方案预览

调整 Loom 工作台布局、导航或审批流程时，先做一份可点击的离线 HTML，供评审者按实际操作顺序走一遍。颜色、按钮和布局沿用 DSH 的现有风格；文案和内容用虚构项目、批次和手册。

1. 在单个 HTML 文件中内嵌样式、脚本和样例数据，双击即可打开。文件名标明方案和版本，页面标注「交互原型」。原型的状态变化在页面内模拟。
2. 让评审者能走完一条关键路径，例如「打开待处理 → 核对本批工作 → 确认或返回」。随 HTML 附上关键状态的截图；涉及面板宽度时，另检查窄版的文字和按钮是否可见。
3. 评审通过后再改产品。用当前组件和隔离测试核对真实查询、状态变更和返回位置。README 的示例图取自当前产品组件，以虚构样例展示已经实现的操作。
